The 5 Components of the STF Ecosystem

Public-good semantic specifications and compiler toolchain hosted at github.com/ais-space.

STF — Semantic Text Format

The core structural format: an explicit semantic section tree with grammar-enforced trust zones (System, UserContent) that are trivially parsed so deterministic host code can filter and strip unauthorized nodes before they ever reach the agent.

Specification Details → · github.com/ais-space/stf

SIL — Semantic Interface Layer

Application extension over STF for AI agent web navigation without parsing raw HTML/DOM or executing JavaScript. Defines 5 conformance profiles and powers the live .sil twin on every page of this website.

Specification Details → · github.com/ais-space/sil

STF-Memory — Structured Agent Memory

Long-term structural memory for autonomous and multi-agent runs: explicit state modeling, conflict tracking, trust provenance, and deterministic projections instead of append-only flat chat logs.

Specification Details → · github.com/ais-space/stf-memory

SIR — Semantic Intermediate Representation

Executable semantic intermediate representation built on STF for AI coding agents, explicit control/data flow reasoning, and verifiable compilation to WebAssembly.

Specification Details → · github.com/ais-space/sir

SIR Compiler — Self-Hosting SIR→WASM

Self-compiling compiler written in SIR itself (~103 KB WASM binary, byte-for-byte self-compilation fixpoint proven, 253/253 tests passing) — practical proof of SIR's resilience across context autocompressions.

Architecture & Proof → · github.com/ais-space/sir-compiler
