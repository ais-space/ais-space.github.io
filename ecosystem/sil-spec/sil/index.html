        CoreMechanism
            Type: Text
            Caption: Agent Web Navigation Without HTML/DOM or JS
            Content: SIL extends STF with an application vocabulary for web pages and interfaces. Agents discover the SIL endpoint via the HTML head link (rel="sil") or visible SIL badges and traverse the site deterministically without rendering DOM trees or running client-side scripts.
