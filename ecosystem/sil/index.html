SIL — Semantic Interface Layer

An application extension of STF enabling AI agents to discover, navigate, and interact with web interfaces through pure semantics — without scraping raw HTML/DOM trees, guessing visual layout, or executing client-side JavaScript.

GitHub: github.com/ais-space/sil → Inspect Live ./index.sil Next: STF-Memory →

Why Web Navigation for Agents Needs SIL

Eliminating HTML/DOM Scraping & Headless Browser Overhead

Today's web agents either scrape megabytes of raw HTML/DOM cluttered with CSS utility classes or spin up heavy headless browsers to render JavaScript and take screenshots. Both paths are slow, expensive in tokens, fragile across UI redesigns, and prone to DOM-injected prompt attacks.

SIL provides a clean parallel representation linked via <link rel="sil" href="./index.sil" type="text/sil"> and visible page links. An agent fetches a concise, deterministic STF tree describing the page's purpose, navigation map, content sections, and interactive capabilities.

The 5 Conformance Profiles of SIL

SIL is structured into 5 progressive conformance profiles so publishers can adopt it incrementally — from static informational sites to full transactional web applications:

  • Profile 1 — Static Content & Navigation (Read-Only): Declares document context, semantic content tree, and explicit cross-page Navigate links (deployed live across all 9 pages of ais-platform.dev).
  • Profile 2 — Structured Discovery & Indexing: Adds canonical metadata, section roles, and typed entity summaries for deterministic agent indexing and retrieval.
  • Profile 3 — Parameterized Queries & Forms: Defines typed input fields, validation constraints, and query actions without requiring DOM form emulation.
  • Profile 4 — Stateful Actions & Transactions: Encodes state transitions, preconditions, confirmation steps, and idempotency semantics for multi-step workflows.
  • Profile 5 — Multi-Turn Agent Collaboration & Streaming: Full bidirectional semantic interaction with trust-zone separation between system UI definitions and untrusted user-generated content.
