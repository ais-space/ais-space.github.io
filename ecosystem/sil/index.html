    Thesis
        Type: Section
        Role: Content
        Caption: Why AI Agents Require Native Semantic Grammar
        Purpose: Rationale for replacing human-oriented visual interfaces and syntax with explicit grammar-level semantics

        HumanVsAgent
            Type: Text
            Caption: Human Perception vs. Machine Semantics
            Content: Existing web interfaces (HTML/DOM/JS), document markups, and programming languages were designed around human visual perception. AI agents waste context capacity inferring structure from visual markup and punctuation, while remaining vulnerable to prompt injection across blurred data boundaries. The STF ecosystem encodes hierarchy, semantics, and trust provenance directly in the grammar.

            Role: Content

        ComponentSIR
            Type: Section
            Role: Content
            Caption: 4. SIR — Semantic Intermediate Representation
