STF-Memory — Structured Long-Term Agent Memory

A structural state model built on STF that replaces flat append-only conversation logs with explicit state nodes, conflict recording, trust provenance, and deterministic projections — preventing memory degradation across long-running multi-agent workflows.

GitHub: github.com/ais-space/stf-memory → Next: SIR → Read .SIL Interface

Why Flat Transcript Logs Fail in Long Runs

From Unstructured Chat History to a Deterministic State Model

Most agent frameworks treat "memory" as either a growing transcript of chat messages or a bag of vector embeddings retrieved by cosine similarity. Over long sessions or multi-agent handoffs, contradictory observations pile up, outdated hypotheses look identical to verified facts, and lossy summarization silently corrupts critical state.

STF-Memory models agent memory as an explicit, versioned STF state tree rather than a chronological stream of prose.

Key Architectural Mechanisms

Explicit Conflict Recording

When two agents, tool outputs, or observations disagree, STF-Memory does not silently overwrite the older entry or leave contradictory lines buried in a log. Conflicts are recorded as first-class semantic nodes linking the competing claims, their evidence, and their resolution status.

Trust Provenance & Authority Scopes

Every memory node preserves its origin and verification level — distinguishing human-approved invariants, execution-verified facts, agent hypotheses, and untrusted external inputs so low-trust data cannot pollute core state.

Focused Projections Instead of Log Dumps

Rather than feeding an agent the entire historical store on every turn, STF-Memory supports deterministic projections: compact, task-specific views of active state, open conflicts, and pending objectives tailored to the subagent's exact role.

Multi-Agent Stability Over Long Horizons

By separating durable state, superseded records, and unresolved conflicts in the grammar itself, multi-agent pipelines run across hundreds of iterations and session handoffs without progressive memory drift.
