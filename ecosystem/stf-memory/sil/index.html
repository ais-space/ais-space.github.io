        StateModelVsFlatLogs
            Type: Text
            Caption: State Model Instead of Flat Append-Only Logs
            Content: Rather than accumulating unstructured conversation transcripts or opaque vector chunks, STF-Memory models knowledge as an explicit, structured STF state tree with clear lifecycles for active facts, hypotheses, and superseded states.

        ConflictTracking
            Type: Text
            Caption: Explicit Recording and Resolution of Conflicts
            Content: Contradictory observations or competing agent conclusions are captured as explicit conflict nodes with linked evidence and resolution status, preventing silent overwrites or hidden inconsistencies.

        TrustAndProjections
            Type: Text
            Caption: Trust Provenance and Task-Specific Projections
            Content: Every memory record carries explicit trust provenance, and agents consume deterministic projections tailored to their active task rather than re-reading noisy full-session transcripts.
