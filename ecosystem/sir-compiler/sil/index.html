        SelfCompilationFixpoint
            Type: Text
            Caption: ~103 KB Binary, Byte-for-Byte Fixpoint, 253/253 Tests
            Content: Written in SIR itself, the SIR Compiler compiles its own source into a ~103 KB WebAssembly binary that achieves a proven byte-for-byte self-compilation fixpoint and passes 253/253 verification tests.

        ArchitecturalDurabilityProof
            Type: Text
            Caption: Practical Proof of Architectural Durability
            Content: The compiler was authored by a comparatively weak model, Tencent Hy3 (with a 200k context window), with final bring-up by Muse Spark 1.3. Notably, Muse Spark 1.3 preserved full correctness when reading and writing SIR code across multiple automatic context compressions without re-reading the language specification, demonstrating that SIR's explicit grammar carries its own semantics locally.
